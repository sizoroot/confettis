🎉 Confettis test page

Build it first with pnpm run test:page and open this file in the browser.

Basic

Bug 1 — removing confettis (some seem to stay or blink)

Many confettis leave the screen or expire at the same time, and none should get stuck.

Bug 2 — falsy values (0 / false) are ignored

Each button should behave exactly as the label says.

Bug 3 — ticks as array

Each confetti should fade out using its own lifetime (short and long ones mixed).

Bug 4 — triangle shape

Bug 8 — resize listener

Press "Create" and "Stop" several times, then resize the window while confettis are falling. The canvas should follow the window size.

Performance — idle loop

Press "Short" and wait. Once the confettis disappear the canvas must be clear and no more animation frames should run (check the Performance tab). Pressing it again must work.

Performance — delta time

The speed and the duration must be the same on any refresh rate (60 / 120 / 144 Hz). Throttle the CPU in the DevTools to see it: the confettis should keep the same pace instead of slowing down. Also switch tabs while they fall: they must not jump when you return.

Several canvases

Each call keeps its own canvas and z-index. The confettis of the second button are drawn in another canvas and finish on their own.

High density screens

On a retina / zoomed screen (or with the browser zoom at 200%) the confettis must look sharp, not blurry.
